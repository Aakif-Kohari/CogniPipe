# Changelog

All notable changes to CogniPipe will be documented in CHANGELOG.md files.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Per-package changelogs are generated by Changesets (see `packages/*/CHANGELOG.md`, `apps/cli/CHANGELOG.md`, `nodes/*/CHANGELOG.md`).
